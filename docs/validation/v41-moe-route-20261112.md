## 2. 逐项语义核对结论（全部有行号）

对照活跃 config（`deepseek_v41_config.json` text_config）：

| 项 | config 值 | 源码语义（行号） |
|---|---|---|
| 打分函数 | `scoring_func=sqrtsoftplus` | `weights = sqrt(where(logits>20, logits, log(1+exp(logits))))`（dsv4_topk.py L88-92；>20 为 softplus(x)≈x 数值护栏）；CPU 侧 biased_topk_cpu 同语义（cpu_router.py L90-107 docstring 明言 "bias steers selection only"） |
| 偏置 | `topk_method=noaux_tc` | `e_score_correction_bias[E]` fp32（model.py L303-313）；**只导选择不进权重**：选择列 = weights+bias（L93-95），权重列 = 无偏 score（L105-108 gather weights） |
| 分组选择 | **无分组** | V4.1 config 无 n_group/topk_group/num_expert_group 键（tests 断言）；router_factory.py L168-173 仅 use_grouped_topk（需显式组键）才走 GroupedTopKRouter——V4.1 走 FusedTopKBiasRouter 平坦 top-k（L215-238） |
| top-k | `num_experts_per_tok=6` | 6 轮平坦 argmax、无放回（选中置 −inf，L110）；平手取**最小专家 id**（L98-109 `min(candidate)`）；NaN 分数 → −1e30 永不选中（L93-95，只要有 ≥k 个有限候选） |
| 归一化 | `norm_topk_prob=true` | `selected_weights *= routed_scaling/sum`（L111-115）；sum≤0 除 1 护栏（fp32 下溢全 0 或 NaN 时触发） |
| 缩放 | `routed_scaling_factor=1.5` | 并入上式单次乘法；**只作用 routed** |
| 共享专家 | `n_shared_experts=1`（inter 2304） | DeepseekV4MLP **无 gate**（与 Qwen3.6 shared_expert_gate 不同）；归一化后以权重 1.0 追加融合槽位（fused_topk_bias_router.py L301-320）或独立相加 |
| 路由 GEMM | — | GateLinear(h→E, bias=False, **out_dtype=fp32**)，ReplicatedLinear 子类（model.py L270-277；gate_linear.py L26）→ 每 rank 全量、logits FP32 |
| EP 归属 | `n_routed_experts=384` | `n_physical(=E+eplb 冗余 0) % ep == 0` **断言整除**（model.py L357-362 mega / L418-421 fused，两路径同式）；`experts_start_idx = ep_rank·n_local`；与 qwen35 pin 的余数规则不同 |
| hash MoE | — | V4.1 主干 `num_hash_layers=0`（v41 nvidia/model.py L155）→ 无 tid2eid 表；DSpark 草稿层（≥40）才覆写 E=128/k=3（L140-147） |
| VL 路由 | vision_config 32 层 | `vision_n_layers>0` → bias_vl[E] fp32 每 MoE 层创建（L314-320）、HAS_VL 哨兵逐行判定（dsv4 L60-70，5 个哨兵 id 才走 bias_vl；文本 token 也付 input_ids 读 + where 判定） |

关键澄清（对照旧仓公式/README 的差异）：
- **不是 V3 的 sigmoid+8 组 4 组选**：V4.1 无任何组键，平坦偏置 top-6；
- **权重不是 softmax/sigmoid 概率**：sqrtsoftplus 无界正分数，逐 token
  归一到 sum=1.5（不是 1.0）；
- **bias 不进权重**（noaux_tc 原义），与"分数+bias 排序取分数"的朴素
  实现在平手/护栏边界不同（NaN→−1e30、sum≤0 除 1）。

## 3. 建模落地（count/memory/IR/config 域）

- **count/moe.v41_moe_route_rows**（三行/层，per-rank 全量复制）：
  - `moe_gate`：FLOPs=2·T·h·E、weight=h·E·B_gate、**act_write=T·E·4（FP32
    logits——修正旧通用行按 b_act 计 bf16 的口径）**；
  - `moe_score`：ops=T·(8E+vl)（sqrtsoftplus 5/elem + bias 加 1 + NaN 护栏
    2/elem；vl=E+2 视觉哨兵判定）、weight=2·E·4（bias+bias_vl）、
    act_read=T·E·4+T·8（logits+input_ids int64 上界）；
  - `moe_topk_renorm`：ops=T·[k(5E+3)+2k+4]（k 轮 argmax + 归一/缩放）、
    act_write=T·k·8（FP32 weights+int32 ids）。
  通用 `moe_router` 行在 v41 层被上述三行替换；`moe_routed`/`moe_shared`
  行不变（shared 无 gate 的既有事实与源码一致）。
- **model_ir**：extras["moe_route"] spec（scoring/topk_method/renormalize/
  routed_scaling/bias 字节数/hash_layers=0/grouped=False）；四键逐行号
  注记；**config 域校验**：scoring≠sqrtsoftplus、topk_method≠noaux_tc、
  norm_topk_prob≠true 一律 ValueError（pinned 源码只支持该组合，不静默
  回退）。
- **lowering/memory**：每 MoE 层 `*-w-moe-route-L{i}` 对象 3,072 B
  （e_score_correction_bias 1536 + bias_vl 1536，FP32 复制不随 tp/ep）；
  count 侧 moe_score weight_capacity 与 memory 侧逐层对账（oracle 在册）。
- **EP 整除**：count/build_model_work 与 memory/target_weight_allocations
  镜像 `require_divisible_ep`——V4.1 族非整除 EP（如 384%7）直接拒绝；
  整除组合（1/2/3/4/6/8/…）放行，E_l=384/ep 整专家。
- **公式注册**：`v2.moe_route_gate/score/topk` 三条（expr+源码行号+适用
  条件）；证据 `ev-vllm-v41-moe`（source-checked，executed=False）；
  source_map `sm-v41-moe-route`（双侧覆盖）+ 旧 `sm-v41-csa2-moe-unverified`
  缩窄为注意力核本体/量化。

**structure_complete 不变（False）**：量化映射、swiglu clamp、稀疏 MLA
注意力核本体、compress_ratios 尾部缺口原样保留；MoE 部分解除的是
"csa2_moe_routing"一项，部署排名资格不因本模块解除。

## 4. 独立 oracle（tests/test_v41_moe_route.py，21 项）

- **§1 pin 完整性**：11 文件 blob sha1 对本地字节与 tree 双侧、SHA256、
  关键源码文本锚点（护栏/平手最小 id/EP 断言/Replicated/num_hash_layers=0）。
- **§2 语义 oracle（纯 stdlib，独立于生产公式）**：sqrtsoftplus 数值与
  >20 护栏、fp32 exp(−87) 下溢；sum(weights)==1.5 精确归一；bias 只改
  选择不改权重（逐 id 核对无偏 score）；全平平手取最小 id；NaN 巨 bias
  不选中；全下溢 sum=0 → 除 1 护卫权重全 0；V4.1 config 无组键（平坦
  top-k 的配置侧证明）。
- **§3 手算绝对值**：T=3 逐字段（gate 11,796,480 FLOPs/act_write 4,608B；
  score 10,374 ops/3,072B/4,632B；topk 34,662 ops/144B）；40 层全模型
  三行；公式绑定不得挪用；tp/ep {1,2,4,8}×{1,8} 逐行复制不变。
- **§4 EP**：ep=7 双侧（count+memory）拒绝；ep∈{1,2,3,4,6,8} 放行；
  ep=8 E_local=48、routed share 逐行复算。
- **§5 count↔memory 对账**：40×3,072=122,880 B 两侧相等。
- **§6 config 域负例**：softmax/grey/false 三非法值拒绝；vision=0 →
  bias_vl 关闭。
- **§7 门禁**：structure_complete 仍 False、gaps 含 swiglu/量化/尾部；
  四栏证据不冒充（cpu_forward=not-run）；replay 冻结（§5）。

既有测试更新（逐项归因，非放宽）：G16/G10/test_model_ir_v02 的
`csa2_moe_routing ∈ unverified_paths` 断言改指 `moe_deploy_variants`
（主干解除后剩余 MegaMoE/DSpark/padding skip 变体）；test_v41_hc 的

## 6. 剩余限制与接口依赖（不冒充）

1. **kernel/CPU forward/GPU 均未执行**（source-checked）；op 为解析算术
   口径（exp/log/sqrt/比较各 1，非 kernel 指令数）。
2. **部署变体未建模**：native MegaMoE（bf16_mega_gate 大批路径，需
   EP+fp4 专家+SP token 分片；deep_gemm 未入 pin）；FP32/bf16x3 router
   GEMM 分层（gate_linear 多档出口）；dsv4_topk Triton 档约束
   E∈{256,384}/k=6/fp32/renormalize（不满足落 ops.topk_hash_softplus_
   sqrt/CPU biased_topk_cpu——语义一致、指令构成不同）；E/k 其他值未独
   立核。
3. **DSpark 草稿层 MoE**（dspark_n_routed_experts=128/k=3、128 专家
   gate_threshold=1）：方法层字段（metadata-only），接口依赖已登记。
4. **quantization_config**（fp8/FP4 专家）不在本 PR：路由行权重按场景
   dense_w 计价，gate 权重未按 checkpoint 量化布局核实。
5. padding skip（VLLM_MOE_SKIP_PADDING）、CUDA-graph 整宽路由缓冲、
   defer_moe_finalize（需 routed_scaling==1.0——V4.1-Flash=1.5 **不适用**，
   已按源码排除）未入账；VL 图像 token 的 bias_vl 选择分支只登记未选路。
6. input_ids 读按 int64 上界计；bias_vl 逐行重复装载按单次权重读计
   （寄存器/L2 效应不在逻辑账本域）。

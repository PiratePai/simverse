## 3. 素数桶锚点（独立 Miller-Rabin 复算，基 {2,7,61}）

- 扫描种子：`engram_vocab_size − 1 = 15,999,999`（L235）；每 ngram 组重置
  起点但 seen 全局不复用 → **15,999,999 之上连续 48 个素数**，层 1 取前 24、
  层 14 取后 24。
- 首 8 素数（硬编码对账）：16000057, 16000079, 16000081, 16000097, 16000121,
  16000129, 16000133, 16000183。
- 层桶和 == config `engram_num_embeddings` **精确相等**（R04 最强锚点）：
  L1 = 384,006,168；L14 = 384,016,682。
- 48 素数全局不重复；offset=cumsum 前缀和单调（末桶右端=行数）。

## 4. 逐算子公式与 op 计数口径（per-rank；V4.1 常数）

| 算子 | 公式（id） | 数值（T=每批 token） |
|---|---|---|
| engram_hash（仅首 engram 层行；批级一次 kernel 算全部 2 层） | `v2.engram_hash`：T·n_layers·(2·max_ngram + 2·(max−1)·n_heads) | T·2·56 = **112·T** FLOPs；读 T·4 B（int32 ids）；写 T·2·24·4 = 192·T B。整数 op 计数：每 (token,layer,shift) 1 mul+1 xor ×4 + shift>0 每 head 1 mod+1 add ×3×8 |
| engram_lookup（每 engram 层） | `v2.engram_lookup`：T·24·256 | **6,144·T** FLOPs（FP8→bf16 dequant 逐元素 1 乘，L726-731）；读 T·24·4 B（ids）；写 T·24·256·b_a；表行读期望流量 6,336·T B（weight_read_expected，重复 n-gram 不去重保守上界，weight_read=0）；容量 = rank 桶和×264 |
| engram_wkv（每 engram 层） | `v2.engram_wkv`：2·T·6144·(25600/tp) | TP1 **314,572,800·T** FLOPs（逻辑参数 6144×25600=157,286,400/层）；权重/容量 6144·(25600/tp)·b_w（列切）；读 T·6144·b_a；写 T·(25600/tp)·b_a |
| engram_post_wkv（每 engram 层） | `v2.engram_post_wkv`：T·hc·(10·d+5) | **204,820·T** FLOPs（d=5120：乘 6d + 加 3(d−1)+d + 标量≈8，解析口径非指令数）；权重/容量 2·4·5120·2 = 81,920 B（bf16 复制）；读 T·(4+5)·5120·b_a + T（mask bool）；写 T·4·5120·b_a |

门控数学（独立 stdlib 复刻核对，d=8/hc=2 小尺寸含正/负 ρ 与 clamp 分支）：
ρ = (Σ hidden·q·k·key)·rsqrt(mean h²+eps)·rsqrt(mean key²+eps)·rsqrt(d)，
eps=rms_norm_eps=1e-20、clamp=1e-6；gate=sigmoid(sign(ρ)·sqrt(max(|ρ|,clamp)))；
out=hidden+gate·value（value=kv 末段共享）。

  TP1 合计 **202,758,032,400 B（≈188.83 GiB）**；各 tp 全 rank 行数守恒。
- wkv：TP1 6144×25600×b_w；Q16（b_w=2）= 314,572,800 B/层；TP8 39,321,600 B/rank/层。
- qk：2×4×5120×2 = 81,920 B/层（bf16 复制，不随 tp 缩放）。
- staged_rows 下界：T×part×256×2 B/层（实际按 max_num_batched_tokens×dp
  分配，运行时常数未 pin，L1749-1756）。
- 表位置（显式 `engram_table_placement`，默认 `cpu_offload`）：研究假设配方
  ——证据 = 源码 cpu_offload/pinned-host 路径（L1037-1039/L1205-1221）+
  101.4 GiB/层客观不可驻留单卡；host 驻留不进 GPU 峰值（host_resident_bytes
  单列披露）；显式 `gpu` 时表计入 GPU（TP8 全 rank 合计仍超 H100 132 GB 标称
  → 如实 OOM）。
- TP 合法性：镜像源码断言 (tp−1)·ceil(24/tp)<24 → 合法 {1,2,3,4,5,6,8}；
  7/9/16 拒绝（负例测试）；6 head 合法但 wkv 25600 不整除 6 → 列切拒绝
  （vLLM 部署配方另受 o_groups 整除约束，实际 tp∈{1,2,4,8}）。

## 7. 限制清单（如实；不冒充）

1. **DP 分片交换未建模**：all-to-all（ENGRAM_A2A_MIN_SLOT=128 切换）、
   EngramPeerExchange/symmetric memory、DPSharedEngramStorage（/dev/shm/
   cuMem 共享）与 EngramBatch MXFP8 打包路径（L1539-1661）——仅 DP>1 且
   无 TP 且 dim%128==0 时启用，本仓默认单副本路径不启用，登记未覆盖。
2. **cpu_offload 运行时行为未建模**：预取流/事件（L1764-1810）、TLB/排序
   阈值 36864/4096（GB200 实测值，L93-102，不进模型）、表行读的 host 带宽
   时延（期望流量只入字节列，时间按 GPU 侧 roofline 计）。表位置默认
   cpu_offload 是**研究假设配方**，不证明实际部署配置。
3. **kernel 内部 op 数为解析近似口径**：哈希 56 op/（token·layer）、门控
   10d+5/（token·hc）是文档约定计数，非 Triton 指令数；sinkhorn 同类近似保留。
4. **staged_rows 为下界**：按场景 T 计，实际按 max_num_batched_tokens×dp
   （运行时常数）分配；V1 slot cache（int32/SWA slot）未建模。
5. **amd/engram.py 变体**未 pin 未建模（ROCm 路径）。
6. **量化映射仍缺**：quantization_config 未映射到计算精度（Engram 表本身
   FP8+E8M0 是 pinned 事实，但 wkv 的量化路径与其他层同缺口）。
7. **structure_complete 仍 False**：CSA2/MoE scoring/noaux_tc/分组路由、
   swiglu clamp、candidate block、compress_ratios[40:43] 尾部、量化映射
   缺口不变；V4.1 不参与部署排名的结论不变。

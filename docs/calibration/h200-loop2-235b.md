## 2. 准入裁决（与 loop1 的差异）

- **TP 集合域 {2,8}**（首条 TP>1 实测覆盖）：sharded 算子
  （attn_pre_proj/attn_rope/attn_post_proj、attention decode 块）为 per-worker
  形状测量，与新仓 gqa 行的 tp 切分口径（heads_c/kv_heads_c，TP8 下 kv 头复制）
  一致（pi-viewer `_resolve_num_kv_heads_per_worker` 源码核对）。
- **TP 不变组**：235B 的 TP1 campaign 只采 replicated 算子（emb/两个 fused
  add+norm），TP2/8 只采 sharded 算子——两campaign互补。replicated 组 per-rank
  全宽、不随 TP 变 → 以 TP1 测量并入 TP2/8 域（manifest `tp_invariant_groups`）。
  emb 为全词表口径，与新仓 embed_lookup 未切分行同尺度。
- **kernel_gap**：TP2 1.5269µs / TP8 1.2384µs（eager；cuda_graph 备选未采用）。
- **MoE 全部 defer**：TP8/EP1 真 128E vllm_fused 数据在册，但新仓 count 的 MoE
  行为整模型口径、memory 按 experts//tp——per-rank 分片账本（V04）未统一前实测
  替换会混尺；TP1/EP4 为 DP4 部署口径不符。**这是本闭环最大的未覆盖部分**。
- 235B 无 TP1 kernel_gap 行 → TP1 场景仍由 30B-tiny set 覆盖（同环境栈）。

94 层全层适用。

按模型形状逐项核对）。
